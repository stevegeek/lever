## Notes

Lever is a containerised, jailed multi-agent orchestration system. A manager
agent drives a fleet of worker agents, each in its own container, and the whole
stack runs inside a jail that keeps a compromised agent away from host secrets
and the local network. It came from a desire to run a multi-agent team on my
own computer, completely isolated from my machine.

The planning was mine with an AI, worked in depth over many rounds. The build,
the tests, the quality reviews and the security checks were all led by an AI,
and each of them also went through many rounds. I have run it, but I have not
read the code, and no human has reviewed it.

Lever is incomplete and in active development. It depends on Scion, which is
itself under heavy development. I use it in some of my own projects and
maintain it with an AI. I make no recommendation either way for now.
